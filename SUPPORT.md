# Support

This repository contains the Tech4Life & Beyond Product Creation Pipeline (validation rules and tooling).

## What we support here
- Product Pack validation rules (`rules/`)
- Validator tooling (`tools/`)
- CI workflow behavior for pack validation
- Documentation that defines required pack structure

## How to get help
1. Open a GitHub Issue in this repository with:
   - A clear title describing the problem (e.g., “Validator fails on missing required section”)
   - Steps to reproduce
   - The exact command used and the full error output
   - The relevant file paths (do not paste confidential content)

2. If the issue affects multiple repositories (e.g., `products` + pipeline rules):
   - Link the related PR(s) and commit SHA(s)
   - State which repo is the “source of truth” for the change

## Confidentiality
Do **not** include:
- Royalty splits or internal allocation details
- Partner/manufacturer names or commercial terms
- Any private/legal/finance material

If the issue is sensitive, contact the organization Owners/Architects privately instead of posting details in an issue.

## Maintainers
Changes to `rules/` and `tools/` require CODEOWNERS review.
